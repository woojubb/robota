A `sessionParticipant` given a `recovery` journal declares `recovery: 'reconcilable'` and recovers a turn a process stopped midway instead of rerunning it. It keeps its journal per conversation and participant, writes the attempt's binding (session, execution, cwd) before the first record of an execution passes through, and answers the roundtable's reconciliation from it: a turn that never began is refunded and started again, a request that got no response is asked again under a new call id, a journaled response completes with no provider call, a turn whose end was journaled is answered from it, and a tool effect that started without a result parks a `reconciliation` request that the host settles with `{ result }` or `{ error }` and that is never run again. Every call the attempt had admitted is settled with the journal's report, refunded when proven never dispatched, or kept counted. A paid tool effect now takes a fresh call id for each admission, recorded in the journal before it is admitted, instead of one derived from the action id, so a resumed attempt can admit it again after recovery refunded the first admission. A recovery journal that is not durable, automatic compaction, and hooks are refused before the lease and the Session open.
