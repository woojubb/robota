# Outcome-first progress updates (owner feedback, 2026-09-23)

During ongoing repository work, keep user-facing updates short and centered on the result, the
next necessary action, and any decision genuinely needed. Do not narrate failed attempts or
retrospective "failure stories" that do not affect the next action. Material blockers and
unresolved failures still must be reported plainly. Trial this preference during the current
delivery; promote it to the communication rule only after it proves useful in real work.
