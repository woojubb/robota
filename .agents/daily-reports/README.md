# Daily work reports (OBSERVABILITY-001) — RETIRED 2026-08-03

**This generator is retired. It is not stalled, and the difference is the point (HARNESS-066).**

Last output: `2026-07-19.md`, while the repository stayed active through 08-02 — three days of
reports, then fourteen days of silence that nothing reported. A reader could not tell a decision from
a lapse, and neither could a scan.

Retired rather than resumed, on evidence rather than preference. A natural experiment already ran in
this tree: this generator is CLOCK-driven and needs an agent to write prose before the artefact is
worth anything, and it lapsed. `.agents/archive/audits/` is EVENT-driven and has output dated
2026-08-02. Same repository, same authors, two cadences, opposite lifespans. A clock-plus-prose
cadence has no recovery pressure — nothing goes wrong when it stops, which is exactly why it stopped
without anyone noticing.

**Retired means the registration is gone, not just the output.** The first attempt at this label left
`scripts/harness/daily-report.mjs` and the `daily-report` skill in place "runnable by hand" — and that
skill was still listed in `.agents/skills/index.md` and still said report generation "**MUST** run as
a background worker", "self-scheduled … near a UTC hour boundary during active work". A RETIRED
directory that a registered skill orders an agent to write to on a cadence is a live contradiction —
the same defect HARNESS-066 was filed about, re-created by its own fix. Review caught it. So the
skill, its index row, the harness script and the script's test are all deleted in the same change;
git history keeps them, which is where a retired thing belongs.

The existing reports stay: they are a record of the days they cover.

## What it was

One **committed** markdown report per **UTC day that had work** (git commits), named `YYYY-MM-DD.md` —
a durable, reviewable record of what was done each day. No-work days had no report. (This lives at
`.agents/daily-reports/`, NOT the gitignored `.agents/reports/` throwaway analysis dir.)

Generated by a harness script and enriched by an agent:

- **Harness** (`scripts/harness/daily-report.mjs`, deleted) — filled the factual sections (commits,
  merged PRs, files/specs/tasks touched) from git history, catching up day-by-day from the last
  report and skipping no-work days.
- **Agent** (the `daily-report` skill, deleted) — authored the `## Summary` prose and committed the
  report.

To recover either, read them out of git history at the commit that removed them; nothing in the tree
depends on them.
