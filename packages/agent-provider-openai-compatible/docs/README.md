# agent-provider-openai-compatible Docs Index

This package owns the DeepSeek, Qwen and Gemma chat providers and the shared OpenAI-compatible
protocol code (its `./shared` entry) that they and `@robota-sdk/agent-provider-openai` are built on.
The [package README](../README.md) covers installation, options and usage.

- [SPEC.md](SPEC.md): the package contract, including executor delegation, structured output and
  tool schema projection.
