# agent-roundtable-robota Docs

`@robota-sdk/agent-roundtable-robota` runs an agent runtime `Session` or a plain `ConversationAgent` agent as an
`@robota-sdk/agent-roundtable` participant, and an agent as its selector: rendering, per-call
metering, approval-wait mapping, checkpoint restoration and release all live here so a host wires up
only its own runtime construction.
