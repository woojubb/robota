# agent-organization Docs

`@robota-sdk/agent-organization` owns the shared canonical JSON and organization resource budget contracts: deterministic, bounded canonical JSON for interoperable resource records, and validators for immutable resource units and budgets. It has no broker, ledger, transport, signing or hosted authority API, and no `@robota-sdk` dependency.
