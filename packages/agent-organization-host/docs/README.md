# agent-organization-host Docs

`@robota-sdk/agent-organization-host` is the private workspace SDK for an operator-owned organization broker: signed workload, request and approval contracts, durable hierarchical budget reservations, fenced task and Git state, and an independently anchored metadata audit. The CLI composes it into an owner-hosted company; local integration does not establish a deployed company's security. The package is not published to npm.
