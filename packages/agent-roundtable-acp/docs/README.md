# agent-roundtable-acp Docs

`@robota-sdk/agent-roundtable-acp` seats an agent that speaks the Agent Client Protocol as an
`@robota-sdk/agent-roundtable` participant: the agent receives only the new public messages of each
turn, keeps its own memory and tools, and the text it says in reply becomes the turn's message.
