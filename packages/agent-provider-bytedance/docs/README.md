# agent-provider-bytedance Docs Index

This package owns `BytedanceProvider`, a ByteDance (ModelArk) video generation provider that
implements `IVideoGenerationProvider` from `@robota-sdk/agent-core` over its own small HTTP client (no
vendor SDK). The [package README](../README.md) covers installation, options, usage and error codes.

- [SPEC.md](SPEC.md): the package contract and its boundaries.
