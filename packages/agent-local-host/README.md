# @robota-sdk/agent-local-host

Node-only authority for owner-controlled local runtime state. Product hosts supply the selected paths and retain responsibility for secrets and admission.

The package is private to the workspace and provides, among other things:

- **Keyring file store** (`createKeyringFileStore`, `KeyringStoreError`): the owner-protected keyring file with its lock, verified writes and typed failure codes.
- **Supervised-runtime control carrier**: the owner-private session directory, the registration record and the Unix-domain socket (Windows named pipe) through which a supervised runtime is registered and reached, with liveness proof (`verifyLiveOwner`, `openRegisteredControlStream`, `listRegisteredCandidates`). The Windows private-descriptor helpers are exported beside it.
- **Supervised-runtime control client** (`requestSupervisedControl`, `listSupervisedRuntimes`, `lockSupervisedSession`, `stopSupervisedSession`, `stopStartedSupervisedSession`, `openSupervisedAttachSocket`): sends one request line to a registered runtime's control socket and takes a reply only when its owner echoes the registration's id and generation, lists every registered runtime with its verified `running` reply, locks or stops a live runtime and waits for its process to exit, and opens the attach socket.
- **Runtime launcher and certified launch** (`startPlainRuntime`, `startSpawnerRuntime`, `startForwardedRuntime`, `launchAndCertifyRuntime`): starts a runtime process from a command, an argument layout and an optional grant handoff the product supplies, waits until the runtime acknowledges it is ready (completing a secure runtime's spawner pair on the way), hands over a transport token only on an inherited pipe, and ends a start that failed; a certified launch proves the runtime it started, installs its owner's trust root, can hand it the daemon role, and stops it if anything after the proof fails.
- **Control admission, attach carrier and launcher handover** (`CONTROL_ACCESS`, `createSupervisedAttachCarrier`, `readSupervisedTransportToken`, `answerHandedOverSpawnerPair`): the table that gives each command of a supervised runtime's control socket its plain and secure admission, the carrier through which a terminal of the same user drives or observes a session, and how a runtime takes its WebSocket token and its spawner's pair from the process that launched it.
- **Runtime custody** (`RuntimeCustody`, `armUncertifiedStop`): decides who may act as the owner of a secure runtime and whether its read keys are open, serves the owner link's sessions, and ends a runtime that nothing certified.
- **Secure surfaces and runtime start** (`SECURE_SURFACES`, `startListener`, `startSecureRuntimeOrExit`, `answerSpawnerPairOrExit`): the table of what every way a product process runs and every listener it opens may be in secure mode with the one gate a listener opens through, and the check that a secure runtime's spawner pair and the secure mode of its state root agree before it listens.
- **Conversation mode choice** (`readProductConversationMode`, `writeProductConversationMode`): the owner-only file that says whether a state root's conversations are plain, preparing or secure.
- **Owner link, workspace daemon prover and start lock** (`openRegisteredOwnerLink`, `openPreparedOwnerLink`, `createWorkspaceDaemonProver`, `proveWorkspaceDaemon`, `acquireSupervisedDaemonStartLock`): opens an owner or spawner link only after proving the selected runtime's certificate and binding, proves over such a link which registered runtime is the daemon serving a workspace, and serializes a workspace's daemon starts with a lock whose removal hint the product supplies.
- **Workspace-root broker** (`startWorkspaceRootBroker`, `requestWorkspaceRootBroker`, `SyncWorkspaceRootBrokerClient`, `secureWorkspaceRoot`): the long-lived process that retains the folders a person approved and performs project file operations against them, its clients, and the selection of the one physical root secure clients and runtimes fence. Its Windows endpoint is a protected named pipe.
- **Broker launcher, trust service and fence** (`ensureWorkspaceRootBroker`, `workspaceRootBrokerEndpoint`, `BrokeredWorkspaceTrustService`, `SecureWorkspaceRootFence`): starts or attaches to one broker per user-state root through a launcher the host supplies, resolves workspace trust and project file access through that broker, and fences the physical root a secure owner or runtime serves.
