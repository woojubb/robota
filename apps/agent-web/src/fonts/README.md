# Remote client fonts

These are unmodified Latin WOFF2 files from the pinned Fontsource 5.3.0 npm archives. Each family directory includes its complete upstream `LICENSE` (SIL Open Font License 1.1). The root layout uses only the weights listed here and loads them from these files, so a build never fetches fonts from the network.
